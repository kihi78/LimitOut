# LimitOut

「ついつい X（旧Twitter）などのアプリを長時間を見続けてしまう」という人向けのアプリ

## 概要
LimitOutは、指定したアプリの連続使用時間を監視し、設定した制限時間に達すると強制的にホーム画面に戻すAndroidアプリです。

## 主な機能
* **ターゲット監視**: 制限したいアプリを指定し、裏側で連続使用時間をカウントします。
* **強制ホーム遷移**: 設定した連続使用時間を超えると、自動でホーム画面に強制遷移させます。
* **アプリ内ブラウザ対応**: X（旧Twitter）などでリンクを開き、アプリ内ブラウザに遷移してもタイマーのカウントを継続します。
* **ゾンビ通知（常駐化）**: 監視中はスワイプで消せない通知を表示。Android 14以降の仕様に対応し、ユーザーが無理やり通知を消しても即座に復活する仕様です。（アプリ内からオフにできます）
* **一定時間停止（スヌーズ）**: どうしても連続で使いたい時は、通知のボタンから指定時間だけ監視を一時停止できます。

## 動作環境
* Android 13 (API Level 33) 以上推奨

## 技術スタック
